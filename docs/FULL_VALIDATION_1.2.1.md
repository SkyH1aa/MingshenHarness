## 本轮修复

- 同一会话在异步准备阶段重复发送时，可能启动重复任务。现在准备阶段也有互斥检查。
- 停止任务时，工作区同步和斜杠命令准备可能继续运行。现在准备过程受取消信号控制。
- 退出时可能先关闭数据库，后台任务再写入状态。现在先取消并等待任务、发送准备和定时任务收尾，再关闭数据库。
- 活跃任务执行超过十分钟后可能从等待记录中移除。现在活跃执行单独跟踪，完成后才开始清理历史等待记录。
- 删除正在运行或等待审批的会话可能与后台写入冲突。桌面和本地 API 现在共用先停止、等待、再删除的流程，并阻止删除期间再次发送。
- 中断工具或会话命名时可能重复保存已持久化的模型回复。现在仅补存尚未保存的流式内容。
- 会话切换仓库后可能复用旧仓库的 worktree 缓存。现在重新校验所属 Git 仓库，保留原有修改并拒绝错误复用。
- 部分协议未发送显式 `none` 思考等级及并行工具设置；现已正确传递。
- Anthropic 分段 usage 可能丢失输入 token；现已合并。三种协议的提前断流、输出限制和不完整响应会报告错误，不再视为正常完成。
- 提前结束读取 SSE 时没有取消源流。现在释放前主动取消未完成的读取。
- 插件 Shell Hook 未套用致命命令拦截，且取消可能等待完整超时。现在执行固定命令保护、取消进程树、限制时间和输出；默认禁用及显式审批仍保留。
- electron-builder 多次解压 `vulkan-1.dll` 时出现 EPERM。打包脚本改为暂存本地原版 Electron 运行时，排除实验 EXE、标记文件和示例应用，再由 electron-builder 构建。

## 自行构建安装包

在仓库根目录 PowerShell 执行：

```powershell
.\package-win.cmd
```

脚本自动查找 Node.js 与 pnpm，生成图标、校验原生运行时、构建应用、检查资源并创建未签名的当前用户 x64 NSIS 安装包。
输出：`apps/desktop/release-artifacts/MingshenHarness-1.2.1-x64.exe`。
只检查前置条件：`.\package-win.cmd --check`。

## 打包复制错误补充修复

用户执行安装包命令时，原版 Electron 的 `d3dcompiler_47.dll` 在暂存阶段遇到 `EPERM`。
复查时该文件可以读取、普通复制及流式写入，当前 ACL 允许写入，未确定错误的外部触发原因。
此前脚本没有处理单次文件访问失败；现对 `EPERM`、`EACCES`、`EBUSY` 使用流式复制回退与最多六次有间隔重试，根目录运行时文件及语言资源均使用 SHA-256 校验。
持续拒绝访问仍会中止，并保留源路径、目标路径和原始错误；缺失文件或内容不一致不会被跳过。

专项验证：`node --test scripts/package-runtime-copy.test.cjs` 五项通过，覆盖快速复制拒绝访问、临时占用与部分文件、持续失败、缺失源文件及内容校验失败。
使用用户本机 `D:\NodeJs\node.exe` 执行 Windows x64 解包构建通过，打包后的资源校验通过。
此补充只修改打包工具，不重跑应用功能验收，也未创建安装包。

## 持续 EPERM 的进一步修复

上述重试未解决用户实际执行中的持续拒绝访问，不能据第一次成功构建认定已消除问题。
随后通过 `.\package-win.cmd --dir` 入口复现了暂存 DLL 及 electron-builder 第二次复制 DLL 的 `EPERM`。
源 `d3dcompiler_47.dll` 的微软签名有效；目录 ACL 允许当前用户读写，失败后独立复制同一路径可以成功。
本机有火绒及 360 运行，但未取得对应的明确拦截记录，不能断言具体防护程序是原因。

部署顺序探测中，先放置原版 Electron EXE，再复制 DLL 的连续六次探测成功。
因此同时修复暂存阶段和 electron-builder 内部并发复制顺序，确保宿主 EXE 完成后才部署配套 DLL。
构建目录改用 `%LOCALAPPDATA%/MingshenHarness/BuildCache`，Node 复制失败时可在此构建目录内使用 Windows 原生文件接口，并验证内容一致性。
没有更改系统安全策略、杀毒开关、白名单或文件来源；不跳过受影响的运行时组件。

专项检查：路径边界、Node/原生复制、持续错误处理及并发部署顺序共十二项通过。
使用用户相同的 `.cmd` 入口和 `D:\NodeJs\node.exe` 完成解包构建与资源校验；生成程序二十一项桌面验收通过，三个关键 DLL 的 SHA-256 与原版一致。
