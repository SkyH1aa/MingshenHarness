# 桌宠动画与交互说明

适用版本：1.3.5。桌宠默认关闭，可在“设置 → 桌面体验”开启。它使用独立透明窗口；角色可以拖动，位置、大小、透明度、置顶和提示偏好保存在本地。更换屏幕后，窗口位置会限制在可见工作区内。

## 右键菜单

右键桌宠、点击更多按钮，或在桌宠窗口使用菜单键 / `Shift+F10` 可打开菜单；气泡按钮打开快捷对话。左键轻拍触发互动，拖动超过阈值后移动窗口；锁定位置后不能拖动。

- “打开主界面”和“快捷对话 (ChatAgent)”分别打开应用与现有快捷 Chat。快捷 Chat 仍使用自己的会话与联网设置，不因从桌宠打开而获得本地文件或其他工具权限。
- “当前任务”展示正在运行会话的标题和思考、执行或等待状态；选择条目跳转对应会话。菜单最多直接列出 20 项，更多任务可打开主界面查看；不存在运行任务时显示空状态。会话标题默认显示，可在桌面体验中关闭并成功保存后使用匿名名称；标题可能包含敏感信息。菜单不显示任务正文、路径、工具参数或审批详情。
- “互动”提供挥手、摸头、点头、摇头、张望、伸懒腰、跳舞、跳跃、喝水、倾听、提醒、阅读和左右行走等动作，并提供休息、唤醒及结束互动。左右行走是动作预览，不代表自动桌面漫游。
- “状态预览”可查看思考、工作、等待、完成、出错和睡眠动作；预览不会修改真实任务状态或伪造任务结果。手动休息不停止 Agent，普通任务事件不会自动将手动休息的桌宠唤醒。
- 置顶、锁定位置、重置位置、大小、不透明度和播放动画可从菜单调整；更多问候、闲聊频率、闲置休息和任务提示设置位于桌面体验。暂时隐藏只隐藏窗口，设置中可再次显示；“关闭桌宠”持久停用，可在设置中重新开启，两者均不退出应用。

桌宠任务提示只使用通用状态，不展示模型回复、文件内容、路径、命令参数或审批详情。闲聊来自应用内置短句，不调用模型或联网。闲聊设为关闭时不主动发言；闲置休息设为 0 时不因闲置自动休息。

任务开始时工作会话面板默认展开，显示标题、状态与本地计算的运行时长；同一会话的运行合并，等待状态优先，可折叠、重新展开或打开对应会话。无活动任务时面板自动收起。标题显示设置保存失败时，桌宠仍可能显示原有标题，需要重试并确认保存成功。“待机趣味动作”可关闭或调整频率；免打扰暂停自动问候、闲聊、待机动作和自动休息，不停止任务或禁用手动互动。

会话跳转不会自动丢弃未保存的消息、项目记忆或跨工作目录文件编辑；遇到离开保护时，先保存或取消编辑后再选择。多个会话正在加载时，最后一次有效选择优先，过期回执不改变当前选择。快捷 Chat 的新建、隐藏及归档会等待相关输入处理和草稿保存，失败时保留原会话供处理后重试。

## 素材与播放

用户提供的 `36个桌宠动画/1.mp4` 至 `36.mp4` 是原始红背景视频，本次处理只读取、不覆盖原片。开发时对边界背景及符合条件的闭合残留区域去色，输出统一 720 × 720、24 fps 的 VP9 Alpha WebM，并映射到 36 个动作 ID。36 条输出合计 4,404 帧：第 20 和 22 条各为 145 帧、约 6.042 秒，其余各为 121 帧、约 5.042 秒。

去色后还会将邻近前景颜色延展到完全透明区域，减轻VP9色度采样将透明红色混入角色轮廓的问题。这一步不改变处理时的Alpha或非透明像素RGBA，但随后的缩放和有损编码不保证像素完全一致。当前36段媒体共47,530,948字节，比该步骤前增加约14.8MB；仍可能保留细微暖边。最终素材哈希、逐帧保护检查及真实Electron解码结果见[1.3.5验证记录](VALIDATION_1.3.5.md)。

视频位于 `apps/desktop/src/renderer/companion-assets/motions/`，同目录的 `manifest.json` 记录源文件和输出的 SHA-256、输出大小、帧数、时长、循环标记、Alpha 抽样和加工参数；打包资源检查使用该清单校验动作文件。重新加工后必须重新核对清单及资源，不能复用旧版本的哈希或大小。构建配置将视频纳入应用资源，正式包仍需实际验证；应用播放时不需要安装 FFmpeg。

开发加工入口为 `scripts/prepare-companion-motions.cjs`，去色逻辑在 `scripts/companion-video-key.cjs`。可先运行 `node scripts/prepare-companion-motions.cjs --help` 查看参数；重新加工须由开发者显式提供本机 FFmpeg 和 FFprobe 路径，工具不会被复制或随应用分发。已有生成结果只有显式传入 `--overwrite` 才会替换。第 21 段为对齐相邻坐姿，去色后整体固定缩放到 512 × 512，再放入 720 × 720 透明画布的 `(101, 208)`；这不是逐帧追踪，也不能保证前后动作无缝。

播放器按状态调度进入、循环和退出片段，使用两个视频槽位并限制加载时间；完成/出错及普通互动不是将真实状态改写为成功或失败。播放暂停或系统开启减少动态效果时卸载视频并保留静态反馈，窗口隐藏时也会卸载视频；资源缺失、解码或加载失败时回退角色静图，不影响 Agent 任务。透明视频和静图都不会获得文件、模型或工具权限。

自动去色和统一画布不能修复生成模型造成的脸部、手部、服装或道具变化，也不能保证复杂半透明边缘不残色、不误抠，片段之间的姿态亦不保证无缝。暖红背景与暖肤色重叠时，皮肤或手指边缘可能出现残红或肤色损失；闭合区域去色也使用条件限制，不能保证保留全部角色细节或移除所有残色。替换或重新处理素材后，应在浅色、中灰和深色背景下逐条检查透明边缘、角色身份、构图及进入/循环/退出衔接，并在实际桌宠尺寸下预览。

较早一轮首、中、末帧的浅色/深色合成联系表位于本机 `.impeccable/review/companion-processed-135/`；这是历史开发检查材料，不随应用分发，也不能代替重新加工后整段动态或多屏验收。

目录结构和提示词仅是开发与素材交接约定；应用目前不提供用户自行导入任意视频包或自动桌面漫游的接口。重新制作素材可参考[36 段图生视频指令](COMPANION_VIDEO_PROMPTS_1.3.5.md)及[素材制作指南](COMPANION_ANIMATION_ASSET_GUIDE_1.3.5.md)。
