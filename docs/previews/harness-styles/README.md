# Mingshen Harness 1.3.0 界面方向预览

直接用浏览器打开 `index.html`。页面使用本地资源，不需要服务器、安装依赖或模型连接。

这是独立的设计原型，没有接入桌面应用，不改变现有简约风格、版本、用户数据或设置。页面中的项目、会话、代码、任务与执行记录均为示例。

三套风格共用同一份页面状态与内容：

- **光轨**：连续的精密工作台，窄工具轨、项目侧栏、宽对话区、上下文工具坞；聚焦与运行时出现局部边缘光。
- **折光**：分离的工作面与轻薄浮层，留出材质层次；玻璃效果局限在工具区域，正文保持稳定实色。
- **脉冲**：更紧凑的任务布局，任务与执行记录占据更明确的位置；状态转换采用短促反馈。

可切换日夜、动效档位和工作视图，也可筛选会话、查看示例文件、展开执行记录、输入演示消息、播放或暂停示例执行。风格在此预览页即时切换，正式应用的“重启后生效”尚未实现。

页面自动遵循系统减少动态效果偏好；切到后台时暂停装饰动画。动效使用 CSS，不运行常驻 JavaScript 逐帧循环。预览选项与演示数据只存在当前页面内存中。

`assets/brand-icon.png` 来自仓库内已确认的原子图标；`assets/icons.svg` 与 `assets/icons.js` 由当前安装的 Lucide React 图标生成，后者保证直接打开本地 HTML 时也能显示图标，许可见 `assets/LUCIDE-LICENSE.txt`。
