## 本轮修复

- 快照与轨迹：会话选择移出标题行，限定输入高度与宽度，长标题可截断；列表窄容器可折行或改为单列，回放操作可换行。切换会话清理旧记录并防止慢请求覆盖新会话。设置导航独立滚动，避免压住版本栏。
- GitHub：设备授权先把公开验证码渲染出来，再打开 GitHub。可以复制、切页恢复、重新打开网页、继续等待或取消。私有 device code 不返回 renderer，取消会终止等待与请求，初始化期间取消不会复活旧授权；Token 仍加密保存。
- 子 Agent：修正提示词中的子任务深度；主 Agent 收到主动识别独立任务、边委派边工作的提示。`spawn_subagent` 返回后台任务 ID，`wait_subagents` 收集真实结果；提前给出最终答复时，执行层会先收集未读取结果再要求继续汇总。步骤耗尽明确报错，不把尚未汇总当完成。
- 并发与安全：自动、手动 `@` 和继续子会话统一从同一入口获取应用级名额。默认 3，可设置 1 至 8，超额排队，唤醒前预留名额；拒绝将上限降低到在跑数量以下，设置页原位置展示错误与保存状态。父任务停止时取消运行与排队子任务，子 Agent 禁止递归，Plan 只能委派只读配置，子会话继承有效扩展引用和原权限/隔离模式。
- 版本与文档：应用、启动/打包入口、SDK 默认版本统一为 1.2.3；三份中英文协议、手册、日志、README、OAuth 说明及 AGENT/AGENTS 同步。协议修订号仍为 `2026-11-03.3`，未改实质条款或数据库 schema。
- 全量检查附带修复：Windows builder 的第二次 DLL 复制再次触发 `EPERM`，改为在本次构建的暂存与输出目录之间移动运行时，移动前后核对 SHA-256，保留验证复制回退。原版 Electron 不移动、不修改。旧桌面 smoke 固定 8.8.8 的断言改为核对实际发布版本。工具完成状态文字提高可读性。

## 1.2.3 审批兼容与备用模型补充

2026-11-04 后续，针对内测中“审批模型可调用但未返回有效裁决”和上游 HTTP/2 stream failed。应用保持 1.2.3。没有从截图推断所有失败都由提示词或本机网络造成：旧解析确实只接受固定格式，也存在上游/网关断流；此前只有概括错误，没有无效回复预览，无法还原每位内测者的具体返回。本轮补强协议约束、明确返回兼容、错误证据及主备恢复。

### 修改

- 审批提示要求一个 `decision` 与 `reason` 的 JSON 对象，decision 固定 allow/deny，reason 可用任意语言；明确拟执行数据不是指令，本地 MCP 仍具有宿主权限。兼容单一明确的 JSON/中英文 verdict、大小写和 JSON 代码块。不把含糊、未知语言自由文本、缺原因、重复键（含转义重复）、冲突字段或多个对象猜成批准。
