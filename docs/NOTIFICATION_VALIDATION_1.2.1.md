日期：2026-11-03。版本保持 1.2.1，不制作安装包。

未重跑 MCP、Docker、沙箱或整个应用的验收。此前全量记录是历史结果，不代表本次工作树

## 实现范围

- 后台会话完成后出现绿色勾选与“已完成 · 未读”，折叠文件夹显示未读圆点。
- 任务栏数字按未查看的已完成会话计数，同一会话只计一次，显示上限 99。
- 查看会话或聚焦当前会话窗口清除标记；未读记录保存在本地，重启后保留。
- Windows 原生任务完成通知支持直接回复，定位原会话并使用普通聊天发送流程。
- 快捷回复沿用原会话的模型、目录和权限；受保护工具仍需审批。
- 重复回调去重，无效、过期、已消费或已删除会话的回复路由不执行。
- 未被接收的回复保留本地失败草稿，重载后恢复到输入框，手动发送被接收后清除。
- 设置 → 外观分别控制原生通知、任务栏数字、标题与摘要预览、声音，支持中文/English。
- 失败或中断不冒充完成；自动子 Agent 结果由父任务汇总，避免重复提醒。

## 复现命令

在仓库根目录运行，端口 9341 和 43129 需空闲：

```powershell
pnpm --filter @mingshen/desktop exec vitest run src/main/desktop/completion-notifications.test.ts
pnpm --filter @mingshen/desktop typecheck
pnpm build
node scripts/notification-smoke.mjs --native
node scripts/notification-smoke.mjs --failure
```

脚本使用独立 `.tmp-notification-smoke-*` 数据目录及本地 HTTP 模拟模型，不使用私人 Key，
不调用付费模型，不启动依赖自动安装。测试不改写正常开发版快捷方式的配置目录。
