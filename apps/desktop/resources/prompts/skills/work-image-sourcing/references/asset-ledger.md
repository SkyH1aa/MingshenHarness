# Image asset ledger template

Use a Markdown table or a local JSON/Markdown note beside downloaded assets. Do not put
secrets or private browsing state in the ledger.

| Field | Example |
| --- | --- |
| Internal asset ID | hero-hall-01 |
| Intended role | Report cover visual |
| Query | modern community hall interior daylight |
| Source page | exact official file/page URL |
| Direct asset URL | final resolved URL, without credentials |
| Creator | recorded creator or organization |
| License | exact license name and version |
| License URL | exact deed or terms URL |
| Attribution required | exact text, if any |
| Commercial use | yes / no / unknown |
| Modification | yes / no / unknown |
| Redistribution | yes / no / unknown |
| Release / privacy caveat | identifiable people or property status |
| Downloaded at | ISO date/time and time zone |
| Local path | workspace-relative path |
| File type | image/png or image/jpeg verified from bytes |
| Dimensions | width x height |
| SHA-256 | full hash |
| Crop / edit | exact operation |
| Final placement | file and page/section |
| Verification | inspected / not inspected |

Do not mark rights as cleared when any material field is unknown. Present the unresolved
risk and use a safer asset instead.
