# Editorial and Visual Acceptance by Format

## Separate the edits

Run a separate content edit and visual edit. In the content edit, remove generic filler,
unsupported certainty, repeated conclusions and text that does not help the reader decide.
In the visual edit, check type hierarchy, grid alignment, whitespace, chart/table legibility,
contrast, page or slide rhythm and the relationship between visual emphasis and actual
importance.

If every section uses the same container, there is no hierarchy. If every element has a
different treatment, there is no system. Use the design presets and native layout controls as
a coherent starting system, then adapt to the audience, language and approved brand.

Applying a theme does not prove design quality. Inspect the actual page or slide, identify the
single most important element, and verify that the composition directs attention there
without hiding necessary nuance.

## Word and PDF

Check the decision-first opening, useful headings, coherent section lengths and terminology.
Verify tables and captions, numbers and units, cross-references, footnotes and references.
Inspect every page for widows, orphans, awkward headings at the page bottom, clipped table
columns, blank pages and unreadable footnotes. The final page should leave a clear decision or
next action. Semantic text extraction does not prove pagination.

## Excel

Check source and calculation separation, formula inventory and input-output identities.
Verify the actual recalculated state before claiming values are current. Check meaningful
number formats, stable headers and filters, practical widths and row heights, readable print
area and page fit. A visually polished workbook with hidden hard-coded derivations or wrong
cache values fails.

## PowerPoint

Titles alone should form a defensible story. Varied layouts must serve the evidence rather
than creating decorative variety. Check type scale, grid alignment, whitespace, source
labels, chart honesty and speaker-note value. Inspect every slide for overflow, collisions,
clipped charts, weak contrast, inconsistent series colors and accidental drift. A structural
OOXML pass does not prove the slides are readable.

## Delivery

Identify the editable artifact, inputs, assumptions, computed/render status and remaining
limitations. A renderer/calculator that could not run is an explicit gap. Do not imply
compatibility, losslessness, statistical certainty or external publication without evidence.
